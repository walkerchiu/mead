# Customer Scope

客戶端介面 — 供已登入客戶使用的功能（如客戶儀表板、個人設定等）。

## 定位

- **對象**：已登入的客戶帳號
- **特性**：需登入、受 RBAC 權限控管（Customer Scope）
- **包含**：客戶專屬的儀表板與功能頁

## 分層

依 Atomic Design 組織：

```
Design System → Atoms → Molecules → Organisms → Layout → Templates → Pages
```

## 現況

此 scope 尚無元件。開始開發客戶端介面時，將 story 的 `title` 設為
`Customer Scope/<層級>/<元件名>`，即會自動歸入此分類。

> 跨 scope 共用的基礎元件請放在 **Shared**，不要重複放進 Customer Scope。
