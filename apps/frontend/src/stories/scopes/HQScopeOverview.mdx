# HQ Scope

後台管理（Headquarters）介面 — 供系統管理員使用的管理功能。
僅收錄 HQ 專屬元件；通用 UI 與認證流程歸於 **Shared**。

## 定位

- **對象**：HQ 管理員
- **特性**：需登入、受 RBAC 權限控管
- **包含**：後台運維介面（稽核日誌、Cron Jobs、Session 管理）、HQ 專屬的
  Layout（MainAppBar）與 Templates（DashboardLayout）等

## 分層

依 Atomic Design 組織：

```
Design System → Atoms → Molecules → Organisms
              → Layout → Templates → Pages
```

`Organisms` 下，系統運維類元件再依功能分子群：

- **Organisms/Audit Logs** — 稽核日誌
- **Organisms/Cron Jobs** — 排程任務監控
- **Organisms/Sessions** — 會話管理

其餘通用 Organisms（Modal、Drawer、Sidebar、各式選單、認證表單等）已歸於
**Shared**，不再列於此處。

## 現況

MEAD 近期聚焦於 Public Scope；HQ Scope 僅保留後台運維專屬元件。
