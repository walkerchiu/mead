# Shared

跨 scope 共用的元件 — 不專屬於任何單一 scope 者放這裡，也涵蓋認證流程。

## 現況

通用 UI 元件（按鈕、卡片、欄位、分頁、選單等基礎 Atoms/Molecules）、
認證流程（LoginForm、ForgotPasswordForm、ResetPasswordForm、TwoFactorForm、
ChangePasswordForm、AuthLayout、登入相關 Pages）、Design System（Colors、
Typography）、通知與錯誤相關共用元件都歸在此 scope。

源碼上對應 `components/<atomicLevel>/`（無 scope 子資料夾）。

## 何時放這裡

- 一個元件被多個 scope 共用、或屬於通用 UI / 認證流程 → 放 **Shared**
- 元件只服務單一 scope → 放對應的 `Public / HQ Scope` 子資料夾
- 各 scope 樣式不同的同名元件 → 各 scope 下各自實作，不要硬塞 Shared

> 不確定歸屬時，預設放 **Shared**。
